# XO v0.2 — C1 contracts as implemented (for C2–C7)

Companion to `2026-11-15-xo-v0.2-ui.md` (section 4.8 is the design; this file is
what C1 actually exports after its review fix round). Read the source when in
doubt; this file lists names and rules.

## Exports

- **Docs, `Stream`, `Composer`, `MicButton`**: default exports, no props.
  `docs/*Doc.tsx` read `route.value.params.id` themselves and call
  `usePanelTitle('…')`. `MicButton` takes `{ large?: boolean }`; its
  aria-label always starts with "Dictate".
- Everything else in `components/` and `shell/` is a named export: `List`,
  `ItemPicker`, `Chip`, `Confirm`, `Palette`, `Help`, `Prompt`, `Overlay`,
  `PinButton`, `SidebarLists`, `Sidebar`, `Panel`, `Toasts`, `TextEdit`.

## Key engine (`lib/keys.ts`)

- `useKeys(bindings, { scope?: 'modal' | 'panel' | 'stream' | 'global', enabled?, descriptions? })`,
  registered in a layout effect. No modes. Single tokens only: `'mod+k'`
  (`mod` = Cmd or Ctrl), `'alt+space'`, `'esc'`, `'up'`, `'enter'`, `'shift+…'`.
- A `stream`/`panel` binding fires only when focus is inside
  `[data-region="stream"]` / `[data-region="panel"]`. The `Stream` root keeps
  `data-region="stream"`, `role="log"`, `aria-label="Conversation"`.
- A field's own `onKeyDown` checks `modalOpen()` first and ignores `e.repeat`
  for Enter. The engine itself never runs a repeated Enter.
- Type-to-composer: printable key without Cmd/Ctrl (Option counts as typing),
  no text entry focused, no modal.
- `keystrokeMark()` / `typedSince(mark)`: take a mark before any await whose
  result might move focus.
- Also: `modalOpen`, `onKeyUp`, `registerCommand`/`commandList`,
  `filterCommands`/`fuzzyScore`, `engine`, `isTextEntry`, `composing`.

## Shortcuts (`lib/keymap.ts`)

`KEY_PALETTE` (mod+k), `KEY_COMPOSER` (mod+j), `KEY_COMPOSER_ALT` (mod+n),
`KEY_SIDEBAR` (mod+b), `KEY_ESC`, `KEY_UP/DOWN/LEFT/RIGHT/ENTER`, `KEY_PTT`
(space), `KEY_PTT_ANYWHERE` (alt+space), `KEY_RECALL_OLDER/NEWER`
(alt+up/alt+down). `SHORTCUTS`/`SHORTCUT_GROUPS` feed Help and the README.

## Focus, layout, router, docs

- `lib/focus.ts`: `registerFocusTarget('composer' | 'panel', getEl)` in a layout
  effect; `focusTarget(name, { queue? })` (sync when registered, else queued 1 s).
- `lib/layout.ts`: signals `singlePanel`, `panelExpanded`, `sidebarOpen`;
  `toggleSidebar`, `toggleExpanded`, `goToComposer()` (use for "new capture"),
  `chatVisible()`, `escAction()`.
- `lib/router.ts`: `route`, `navigate(path, { replace? })`, `back()`,
  **`closePanel()`** (always use this to close a document, never `navigate('/')`),
  `parseRoute`, `formatRoute`, `isPanelRoute`, `parentPath`.
- `lib/nav.ts`: `DocRef`, `docPath(ref)`, `openDoc(ref, { focus? })`,
  **`openDocAsync(ref, mark)`** (after an await), `isPinned(kind, id)`;
  `togglePin` and the recents call are C2's.
- `lib/commands.ts`: `startMeeting(personId)`, `createPerson(name)`,
  `createProject(title)`; epoch-guarded, open via `openDocAsync`.
- `lib/api.ts`: `get`, `post`, `put` (no body unless given), `patch`, `del`, `postAudio`.

## Store (`lib/store.ts`)

`projects`, `refreshProjects()`, `nav`, `refreshNav()`, `panelTitle`,
`usePanelTitle(title)`, `personName(id)`, `projectTitle(id)`, `askPick(kind, onPick)`,
`askConfirm(message, onYes)`, `askText(label, onSubmit)`; kept from v0.1:
`chatDraft` + helpers, `drafts`, `flash`, `epoch`, `session`, `shellActive`,
`searchQuery`, `overlay`, `togglePalette`, `closeOverlay`, `undoLastCapture`,
`logout`. Gone: `mode`, `requestFocus`, `useFocusRequest`, `personPicker`.
`projects`, `nav`, `people`, `panelTitle` clear when the session becomes null.

## List (`components/List.tsx`)

`{ items, label, render, actions, empty?, scope?: 'panel' | 'modal' }` plus,
optionally, `{ onAdd, draftId, addPlaceholder? }`. **`draftId` is required with
`onAdd` and must include the owning entity** (e.g. `person:12:agenda`). Bindings
active only while the listbox has focus. Highlight is visual plus a live region;
Up/Down rows, Left/Right chips, Enter runs (default first action); `danger`
actions go through `askConfirm`. Text kept when `onAdd` rejects.
`ItemPicker`: `{ kind, onPick, onCancel, allowNone? }`. `Chip`:
`{ label, onClick, highlighted?, danger? }`.

## Panel, Esc, palette

- `Panel` has `data-region="panel"`, `role="region"`, `aria-label="Document"`;
  persistent across doc changes, inner doc keyed.
- Esc ladder: modal layers → blur a panel text field (saves) and focus the
  panel → close the document (`closePanel`) and focus the composer → focus the
  composer.
- Palette commands run on the next tick after the palette closes.

## CSS

Tokens only (`styles/tokens.css`): `--bg`, `--bg-sidebar`, `--bg-raised`,
`--bg-hover`, `--bg-selected`, `--fg`, `--fg-muted`, `--border`, `--accent`,
`--accent-fg`, `--danger`, `--focus`, `--scrim`, `--shadow`, `--radius`,
`--radius-sm`, `--font`, `--mono`, `--text`, `--leading`, `--s1`…`--s6`,
`--sidebar-w`, `--chat-max`. Classes in `components.css`: `.btn`, `.btn.primary`,
`.icon-btn`, `.chip`, `.input`/`.textedit`, `.list`, `.row`, `.row-body`,
`.row-chips`, `.overlay`, `.dialog`, `.results`, `.hint`, `.empty`; `base.css`:
`.muted`, `.sr-only`. One CSS file per area (`stream.css`, `voice.css`, …); no
colour or font literals outside `tokens.css`; no inline styles (CSP).

## e2e (`e2e/helpers.ts`)

`test` (logged in via shared storage state), `expect`, `api(page, method, path, body?)`,
`seedPerson`/`seedProject`/`seedNote`/`seedAction` (page must be on `/` first),
`sel`, `loginWithKeyboard`, `nextTotpCode()`, `mouseCount`,
`noHorizontalOverflow`, `EXPECTED_401`; fixtures `diag` (fails on console
errors/CSP; `diag.allow(re)`) and `sparePage(n)` (n = 1..4, for logout/lock
tests). Run one spec: `pnpm e2e e2e/<area>.spec.ts`. Use area-prefixed seed
names so parallel specs sharing the DB don't collide.
